# ASSUMPTIONS

1. The user wants to study the main Remora library (`src/remora`) first, with demos/tests as secondary material.
2. "Entry points" means both executable startup points (CLI scripts, `__main__`) and architectural handoff modules where control enters core subsystems.
3. A useful study plan should follow actual runtime flows, not alphabetical package order.
4. The user benefits from a prioritized sequence that minimizes context switching between unrelated subsystems.
