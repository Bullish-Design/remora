## Issue Format

When blocked, create `ISSUE_XXX.md` in this directory with:

```markdown
# ISSUE-XXX: [Short Title]

## Problem
What's happening?

## Expected
What should happen?

## Attempts

### Attempt 1
What was tried, what happened, why it failed.

### Attempt 2
...

### Attempt 3
...

## Analysis
What patterns do we see? What's the root cause hypothesis?

## Next Steps
What should be tried next?

## Resolution
How was it finally resolved?
```
