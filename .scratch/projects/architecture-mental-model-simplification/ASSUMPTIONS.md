# Assumptions

- Primary goal is cognitive load reduction: developers should hold the architecture in a small, stable mental model.
- Existing cycle removal work is largely complete; current pain is coupling density and hub concentration.
- We should optimize for explicit boundaries and predictable dependency direction, not only acyclic graphs.
- Refactor should be incremental and verifiable with Tach rules/graphs at each phase.
- Project is resumed in later sessions, so all context and artifacts must be self-contained in this directory.
- No subagents are allowed.
